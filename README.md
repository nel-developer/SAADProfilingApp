# SAADProfilingApp

SAADProfilingApp is a mobile Flutter application designed to help SAAD profile farmer beneficiaries, even in areas without internet connectivity. Users can record beneficiary data offline and upload it to the database once internet access is available.

## Project Structure

- **lib/**: Contains the main Flutter code (UI, business logic).
- **assets/**: Images, icons, and other resources used in the app.
- **test/**: Unit and widget tests for the application.
